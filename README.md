# WearIt

WearIt is a responsive fashion storefront built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**. Browse clothing and shoes, view product details, manage a cart, and explore the sign-in and registration screens.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available routes

- `/` — Home page
- `/pages/clothes` — Clothing catalog
- `/pages/shoes` — Shoes catalog
- `/pages/shop-item` — Product details
- `/pages/cart` — Shopping cart
- `/pages/sign-in` — Sign-in screen
- `/pages/join-us` — Registration screen

## Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run start    # Run the production build
npm run lint     # Run ESLint
```
